# ContextOS V1 Evaluation

This directory contains the final V1 validation materials for ContextOS.

## Files

- `evaluation-plan.md`: how V1 should be evaluated without changing scope.
- `videos.md`: public video test set with pre-labeled expected modes.
- `personas.md`: deterministic local profile personas for policy and personalization tests.
- `evaluation-results.md`: actual results collected in the current repository run.
- `known-limitations.md`: honest limitations for release and hackathon judging.
- `release-checklist.md`: final local release verification checklist.
- `hackathon-submission.md`: concise submission copy and demo flow.

## Important Note

This evaluation separates:

- **Automated/fixture results**: tests that were actually run locally.
- **Manual/live results**: tests requiring a browser, Gemini project access, Cloud Run, Firestore, or live YouTube.

Do not convert fixture-only results into claims about live Gemini behavior.
